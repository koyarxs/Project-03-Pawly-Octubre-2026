## Correcciones detectadas durante la revisión

1. El worker escribía `CAPTURED` para Mailpit, pero la restricción de PostgreSQL no aceptaba ese estado. Se agregó la migración `20261028000000_booking_notification_captured`, preservando las condiciones de destinatario único e intentos no negativos. No se editaron migraciones anteriores.
2. Los runners de autenticación y navegador no incluían `PatientDocument` en la limpieza de sus esquemas. Ahora la incluyen explícitamente y mantienen `RESTRICT`.
3. Las pruebas heredadas asumían que propietario/administración editaban la web y que el registro de clínicas estaba disponible con una clínica vinculada. Los fixtures ahora separan esos escenarios y comprueban el editor exclusivo.
4. Se actualizaron pruebas de portada que buscaban secciones retiradas y el acceso móvil anterior. Se conservaron comprobaciones de seguridad del contenido, fallback, mapas y responsive.
5. El recorrido documental ahora ingresa el RUT, sigue los pasos nuevos de reserva y espera que los servicios terminen de cargar antes de fotografiarlos.

## Reproducibilidad y límites

Comandos y preparación: [README](../README.md#pruebas-y-capturas). PostgreSQL y Mailpit deben estar disponibles localmente. Los puertos de QA son 3100 y 4001. En Windows se usa `npm.cmd` y Edge.

Las primeras ejecuciones encontraron Docker detenido y bloqueo de descarga de fuentes dentro del sandbox. Se inició Docker y se compiló con acceso de red; esos intentos fallidos no se cuentan como validación. El contenedor PostgreSQL existente conserva el nombre anterior del proyecto; no se reinicializó ni se borró su volumen.

No se ejecutó toda la colección histórica de Playwright ni un despliegue. Los resultados anteriores cubren las suites indicadas, no certifican producción. No se enviaron mensajes a destinatarios externos. Gmail, claves privadas y cuentas locales no forman parte del commit.

Las migraciones se probaron en esquemas aislados; hacer push o abrir el PR no las aplica a una base de operación. Las propuestas de `work/`, las vistas previas de `output/`, los logs y credenciales de `tmp/` quedan fuera del repositorio.
