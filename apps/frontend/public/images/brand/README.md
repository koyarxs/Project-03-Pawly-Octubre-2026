# Identidad de Porvenir

Adaptaciones del logo entregado por el usuario el 22 de octubre de 2026, preparadas con la herramienta de imágenes de OpenAI.

- `porvenir-logo.png`: marca horizontal con fondo transparente; cabecera, pie, autenticación y navegación del sistema.
- `porvenir-emblem.png`: emblema compacto para iconos y favicon.

El componente compartido `components/brand.tsx` mantiene una sola identidad para las pantallas públicas y privadas. En superficies oscuras, la marca completa usa un panel blanco para preservar el contraste y los colores del original. Las variantes son adaptaciones rasterizadas, no archivos vectoriales originales.
